# Brief2Ship v0.4 Free Scraping Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add free, local, evidence-preserving scraping and bounded crawling to Brief2Ship without paid APIs, anti-bot bypasses, or a heavyweight framework.

**Architecture:** Add a zero-runtime-dependency Python package and `brief2ship` console entrypoint. Standard-library networking owns URL safety, redirects, robots.txt, limits, and sequential crawling; standard-library HTML extraction is always available, with Apache-2.0 Trafilatura as an optional extraction adapter. Results are structured JSON/Markdown receipts with source URL, timestamps, hashes, and warnings.

**Tech Stack:** Python 3.11+, `urllib`, a small RFC 9309 longest-match robots parser, `html.parser`, `ipaddress`, `socket`, `unittest`; optional `trafilatura>=2.1,<3`; GitHub Actions.

## Repo-first decision

Target: public-page text extraction and same-origin bounded crawling, local-only, no paid services, respectful defaults, portable to Linux/macOS/Windows.

**Choice:** clean standard-library safety/fetch layer, optional Trafilatura library adapter. No fork. Selective inspiration from Crawlee/Scrapy robots and request-limit patterns.

## Product contract

Allowed:

- public HTTP/HTTPS pages
- single-page extraction
- same-origin sequential crawl
- robots.txt compliance
- explicit local/owner-authorized testing through `--allow-private`
- HTML/plain-text extraction to JSON, Markdown, or text
- source hashes, timestamps, final URLs, warnings, and receipts

Blocked by default:

- private/loopback/link-local/reserved/multicast hosts or IPs
- URL credentials
- non-HTTP schemes
- cross-origin crawl expansion
- login/session/cookie automation
- CAPTCHA or anti-bot bypass
- proxy rotation/fingerprint evasion
- unbounded crawling or concurrency
- oversized/non-text responses
- ignoring robots.txt

## Stable interfaces

```python
@dataclass(frozen=True)
class ScrapeConfig:
    timeout: float = 15.0
    max_bytes: int = 2_000_000
    max_redirects: int = 5
    user_agent: str = "Brief2ShipBot/0.4 (+https://github.com/five0nit/brief2ship)"
    min_delay: float = 1.0
    allow_private: bool = False
    extractor: str = "auto"

@dataclass
class ScrapeResult:
    requested_url: str
    final_url: str
    fetched_at: str
    status_code: int
    content_type: str
    title: str
    text: str
    links: list[str]
    extractor: str
    bytes_read: int
    sha256: str
    robots_url: str
    robots_allowed: bool
    warnings: list[str]
```

CLI:

```bash
brief2ship scrape URL [--format json|markdown|text] [--output PATH]
brief2ship crawl URL --output DIR [--max-pages 5] [--max-depth 1]
brief2ship doctor
```

`--allow-private` is an explicit local/owner-authorized test switch. It never disables robots, size, timeout, redirect, or crawl limits.

### Task 2: URL and network safety

**Files:** `src/brief2ship/safety.py`, `tests/test_safety.py`

1. Test scheme/credential/host/port validation.
2. Test rejection of loopback, private, link-local, reserved, multicast, unspecified, `.local`, and `localhost` targets.
3. Resolve DNS and reject a hostname if any resolved address is unsafe.
4. Revalidate every redirect target.
5. Permit explicit private test targets only when `allow_private=True`.
6. Run tests and commit.

### Task 3: Robots and bounded fetching

**Files:** `src/brief2ship/fetch.py`, `tests/test_fetch.py`

1. Add fake-opener tests for 2xx/404/403/5xx robots responses.
2. Fail closed on robots 401/403, malformed policy, network failure, or 5xx; allow absent 404/410.
3. Parse user-agent groups, `Allow`, `Disallow`, `*`, `$`, and `Crawl-delay` with longest-path-match semantics; add regression tests because Python's `RobotFileParser` uses first-match rule order.
4. Manually follow at most five redirects, revalidating each URL.
5. Stream at most `max_bytes`; reject oversized `Content-Length` early.
6. Accept `text/html`, `application/xhtml+xml`, and `text/plain` only.
7. Capture status, final URL, bytes, content type, raw SHA-256, and timestamp.
8. Run tests and commit.

### Task 4: Extraction adapters

**Files:** `src/brief2ship/extract.py`, `tests/test_extract.py`, `tests/fixtures/article.html`

1. Test title, article paragraphs, headings, list items, links, entity decoding, and script/style/nav/form removal.
2. Implement deterministic stdlib `HTMLParser` extraction.
3. Add optional Trafilatura adapter; `auto` uses it when installed and falls back with a warning.
4. Never send content to a model or remote extraction service.
5. Run tests and commit.

### Task 5: Single-page scrape and receipts

**Files:** `src/brief2ship/scrape.py`, `src/brief2ship/render.py`, `tests/test_scrape.py`, `tests/test_render.py`

1. Compose safety -> robots -> fetch -> extract.
2. Render deterministic JSON with provenance fields.
3. Render Markdown with title, source, final URL, fetched time, hash, extractor, warnings, and extracted text.
4. Text output contains extracted text only.
5. Atomic output writes; stdout when no output path.
6. Run tests and commit.

### Task 6: Same-origin bounded crawl

**Files:** `src/brief2ship/crawl.py`, `tests/test_crawl.py`

1. Breadth-first, same-origin only, fragments removed, duplicate URLs suppressed.
2. Defaults: max 5 attempted URLs, depth 1, hard caps 20 attempts/depth 3; failures consume the page budget.
3. Sequential requests only; delay is `max(min_delay, robots crawl-delay)`.
4. Cache robots per origin.
5. Continue after a page failure but record it in the crawl receipt.
6. Write `manifest.json`, `pages/NNNN.json`, and `pages/NNNN.md` atomically.
7. Run tests and commit.

### Task 7: CLI integration

**Files:** `src/brief2ship/cli.py`, `tests/test_cli.py`

2. Exit codes: `0` success, `2` CLI error, `3` blocked by policy/robots, `4` fetch/extraction failure.

## Release gates

```bash
python3 -m unittest discover -s tests -v
python3 scripts/validate-docs.py
python3 scripts/validate-release.py
python3 -m build
# clean venv install + brief2ship doctor/scrape/crawl round trip
git diff --check
```

Security/adoption gates:

- robots denial produces no page fetch
- private targets blocked by default
- redirects cannot reach blocked networks
- response cap enforced while streaming
- no credentials/cookies/CAPTCHA/evasion path
- crawl is same-origin, sequential, delayed, and hard-bounded
- every success carries timestamp, final URL, raw hash, extractor, robots status, and warnings
- zero paid APIs/keys required
