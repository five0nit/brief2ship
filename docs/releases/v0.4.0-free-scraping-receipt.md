## Safety contract proved

- HTTP/HTTPS only.
- URL credentials rejected.
- Invalid/zero ports rejected.
- Internationalized hosts use IDNA and Unicode paths/queries are encoded before transport.
- Private, loopback, link-local, reserved, multicast, and unspecified targets blocked by default.
- Mixed public/private DNS answers fail closed.
- Every redirect target is revalidated.
- Cross-origin page redirects are blocked.
- Same-origin redirect paths are re-evaluated against robots rules before fetch.
- robots.txt checked before page fetch.
- robots 401/403 denied; other 4xx/5xx/network/malformed failures fail closed; 404/410 absence recorded.
- Longest matching robots path wins; wildcard, end anchor, exact product-token, percent-normalization, and allow-tie behavior tested.
- Cached robots documents are re-evaluated for every requested path.
- Robots denial causes no page request.
- Response content type and byte limits enforced.
- One total wall-clock deadline covers connect, redirects, and streamed response bodies.
- Unknown charsets become typed extraction failures; terminal/bidirectional controls are stripped.
- Untrusted title, warning, provenance, and content fields are inert code-fenced in Markdown receipts.
- Same-origin, sequential, depth-bounded crawl.
- Failed/denied URL attempts consume the page budget.
- Crawl output directory must be new or empty, preventing stale/fresh receipt mixing.
- No credential headers, cookies, browser automation, CAPTCHA bypass, fingerprint spoofing, proxy rotation, or concurrent/distributed crawler path.

## Expected failures and alternatives

1. `python3 -m build` initially failed because the active Hermes virtual environment lacked `build`. A clean temporary build environment installed `build==1.5.0`; wheel and source archive then built successfully.
2. A first local HTTP smoke port was occupied. A fresh ephemeral port served the skill successfully.
3. Hermes then refused localhost HTTP and local-directory skill sources. No workaround was used to claim native-install success. The final remote install gate remains pending until an immutable public tag exists.
4. Initial Windows test execution exposed implicit CP1252 decoding in release tests. All text reads were changed to explicit UTF-8; the complete Windows suite then passed.
5. Initial robots caching stored a path decision instead of the rules document. It was corrected and regression-tested so each path is independently evaluated.
6. Initial crawl accounting capped successes instead of attempts. It was corrected so failures consume the request budget.
7. A timed-out adversarial review still produced useful probes: substring robots-agent matching, percent-encoded path mismatch, accepted unhandled 304, unknown charset leakage, slow-drip timeout extension, active Markdown, and terminal controls. All were corrected and regression-tested before this receipt was finalized.

## Known limitations

- Static HTML/plain-text only; no JavaScript/browser rendering.
- No authentication, cookies, PDFs, images, or media extraction.
- Page redirects to a different origin require an explicit second scrape so the new origin's robots file is checked first.
- DNS is validated before each request, but the standard-library transport resolves again during connection. A hostile DNS-rebinding service remains a residual risk. Do not expose this CLI as a multi-tenant service without pinned-address transport and sandboxing.
- The custom robots parser intentionally implements the bounded product subset: user-agent groups, Allow, Disallow, `*`, `$`, and Crawl-delay.
- Public content can change after a receipt; compare hashes before treating an older artifact as current evidence.
