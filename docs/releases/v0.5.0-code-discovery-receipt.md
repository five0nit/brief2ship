## Scoring and decision limits

- Feature matching is deterministic token/evidence coverage, not semantic proof.
- Dependency counts are declared direct runtime counts, not complete transitive graphs.
- OSV empty results mean no known result for the exact query, not proof of safety.
- `use-as-library` requires exact package-version OSV completion.
- Any OSV finding blocks reuse until severity and remediation are reviewed.
- Missing/ambiguous or non-permissive license, archive, deprecation, gating, disablement, or failed bounded tests block reuse.
- Coverage and unknown-cost fields expose incomplete evidence separately from the `/100` score.
- Uninspected GitHub identities remain `observed-unpinned`; inspected repositories record the actual commit.
- Hugging Face artifacts without a canonical GitHub repository are scored but not cloned.
- No recommendation authorizes execution, publication, or license acceptance.

## Residual limits

- GitHub-reported size and post-clone retained-disk checks do not provide an operating-system filesystem quota during the clone itself.
- GNU `timeout` command-group termination is used when present; other platforms retain Python's process timeout behavior.
- Bubblewrap is currently the only supported candidate-execution sandbox; Windows and macOS fail closed.
- Static evidence and a bounded sandbox pass cannot prove absence of malicious behavior or license incompatibility.
- Public APIs can change schemas, quotas, and results.
