## Compatibility defect and fix

Brief2Ship's custom `urllib.request.HTTPSHandler` matched the Python 3.11 call shape and forwarded:

```python
check_hostname=getattr(self, "_check_hostname", None)
```

Python 3.12 and Python 3.13 removed that deprecated keyword from `http.client.HTTPSConnection.__init__`, causing:

```text
TypeError: HTTPSConnection.__init__() got an unexpected keyword argument 'check_hostname'
```

The fix removes only the obsolete forwarding. The secure `SSLContext` remains attached to the logical hostname while the socket still connects only to validated pinned DNS answers.

## Security invariants verified

- `SSLContext.check_hostname == True` on Python 3.11, 3.12, and 3.13;
- `SSLContext.verify_mode == CERT_REQUIRED`;
- TLS SNI and certificate matching continue to use the original hostname, not the pinned IP;
- `https://example.com/` succeeds through the pinned transport;
- `https://wrong.host.badssl.com/` fails with `SSLCertVerificationError` for hostname mismatch;
- private/reserved address rejection, redirect revalidation, proxy suppression, robots checks, response limits, and crawl bounds are unchanged.

An independent read-only review returned **PASS** with no commit blocker.

## First GitHub CI correction

The first `v0.6.1` source push ran GitHub Actions at <https://github.com/five0nit/brief2ship/actions/runs/33832641356>. Six jobs passed; Windows Python 3.11 failed only `test_empty_response_cannot_finish_after_wall_clock_deadline` because the test relied on a real `sleep(0.06)` crossing a `0.05` deadline. The test now drives `_read_limited` with a deterministic mocked monotonic clock before/after an empty read. The focused regression passed 100 consecutive iterations on each of Python 3.11, 3.12, and 3.13.

Replacement GitHub Actions run <https://github.com/five0nit/brief2ship/actions/runs/33834131248> passed all seven jobs: Ubuntu and Windows on Python 3.11/3.12/3.13 plus the optional Trafilatura adapter. The immutable-tag gate is satisfied.
