## CLI improvements

### Local workspace source

```bash
brief2ship discover "TARGET AND CONSTRAINTS" \
  --local /path/to/scoped/workspace \
  --sources local,github,pypi,npm,crates,huggingface \
  --per-source 10 --limit 10 --inspect-top 3 \
  --output /tmp/brief2ship-preflight-...
```

Properties:

- repeatable `--local PATH`;
- `--sources local` supports offline local-only discovery;
- supplying `--local` automatically enables the local source;
- maximum five roots;
- round-robin breadth-first traversal prevents a broad root or deep subtree from starving another root;
- maximum 10,000 visited directories, 10,000 entries and 2,000 retained filenames per directory, depth 16, 500 candidates, and the shared wall-clock timeout;
- local and static-inspection reads use bounded no-follow descriptors;
- hidden/VCS/vendor/dependency/build/cache and symlinked directories skipped;
- manifests or an actual Git checkout establish project identity; README-only nested folders do not;
- selected local projects are statically inspected in place;
- no local candidate code executes during normal discovery.

### Local credential safety

An independent review found that an intermediate implementation could expose credentials embedded in a non-GitHub Git remote and could read a symlinked `.git` directory. Final implementation:

- rejects credential-bearing remotes;
- strips remote query and fragment data;
- does not follow symlinked `.git` metadata;
- has regressions proving secret text never enters candidate receipts.

### Stronger public evidence

Inspected GitHub candidates now record:

- contributor count from the paginated contributors endpoint;
- real watchers/subscribers rather than GitHub's star alias;
- forks;
- true issue-only count and issue ratio; uninspected combined issue/PR counts receive no penalty;
- homepage/demo URL;
- existing security/community, license, activity, tests, CI, docs, examples, source, and dependency evidence.

The `/5` adoption-health component now combines adoption, forks, watchers, contributors, and an explainable issue-health penalty.

Matching local clones retain in-place inspection even when deduplication selects a GitHub or package candidate as the primary record.
